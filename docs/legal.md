## 2. 关于教材：我们引用了什么，没引用什么

本项目收录了同济大学《高等数学》上册（第八版）的**知识结构**。

### ✅ 收录的内容（事实性信息，不受版权保护）

- 书名、作者、出版社、版次
- 章节编号与章节标题（"第 3 章 微分中值定理与导数的应用"）
- 定义名与定理名（"罗尔定理"、"函数在一点处的导数"）
- 数学内容本身（定理的陈述、证明方法）—— 数学发现不是版权客体

### ❌ 没有收录的内容

- 教材正文的任何段落原文
- 教材的例题、习题、习题解答原文
- 教材的插图、排版、图表

### 每个条目都是怎么来的

打开 `data/books/chapter-3.js` 会看到每个条目的字段来源：

| 字段 | 来源 |
| --- | --- |
| `name` | 教材里的定理名（事实性标题） |
| `statement` | **本项目原创撰写的严谨表述**（数学命题是公共知识，表述是自己的） |
| `plain` | **本项目原创**：用大白话 + 生活比喻重新解释 |
| `why` | **本项目原创**：证明思路是怎么想出来的 |
| `proof` | **本项目原创撰写**的完整证明过程（证明方法是公共知识，行文是自己的） |
| `example` | **本项目原创编写**的例子 |
| `pitfalls` | **本项目原创**总结的易错点 |

也就是说：**教材提供了"有哪些定理"，我们提供了"怎么讲才听得懂"。**

### 如果你想移除某本教材

`data/books/registry.js` 里删掉对应条目即可，代码无需改动。

## 3. 关于题库：只接开放许可或自有的

### 内置题库

`data/questions/*.js` 里的 194 道题全部是**本项目原创编写**的，
以 CC-BY-4.0 发布，`source` 字段均为 `original`。

### 外部题库（实时题库功能）

`js/bank.js` 支持从外部 JSON 地址实时拉取题目合并。**这个功能是空的管道**，
项目本身不预置、不抓取任何第三方题库。

**建议接入的来源**：

| 来源 | 许可 | 备注 |
| --- | --- | --- |
| [OpenStax](https://openstax.org) | CC BY 4.0 | 大学教材配套题库，可商用，保留署名 |
| [MIT OpenCourseWare](https://ocw.mit.edu) | CC BY-NC-SA 4.0 | 非商用 |
| [Wikibooks](https://www.wikibooks.org) / Wikiversity | CC BY-SA 4.0 | 相同方式共享 |
| [Khan Academy](https://www.khanacademy.org) | CC BY-NC-SA（部分） | 逐项确认许可 |
| 你自己 / 你所在学校自编题库 | 你说了算 | |

**请务必确认**：目标资源的页面上写了什么许可、是否允许再分发、是否要求相同方式共享。

### 明确不要做的

- ❌ 抓取商业题库（各类付费刷题网站、App）
- ❌ 抓取考研机构题库、模拟题
- ❌ 扫描/OCR 教辅书、习题集、答案册
- ❌ 把别人的付费内容转成 JSON 挂在自己的静态托管上
- ❌ 用本项目的实时题库功能去绕开任何网站的访问限制

`scripts/fetch-open-bank.mjs` **只是格式转换器**：你给它一个 JSON 文件或 URL，
它转成本项目格式。它不内置任何题库地址，不做爬虫。

## 4. 隐私

- 没有后端、没有账号、没有遥测、没有埋点。
- 学习数据（错题本、收藏、复习进度、统计）全部在你自己浏览器的 `localStorage` 里。
- 唯一可能的外部请求是：你在「数据与设置 → 实时题库」里**主动填写**的题库地址。
  不填就不会有任何外部请求。
- 清空数据：「数据与设置 → 清空所有数据」。导出的 JSON 完全由你自己保管。
